# Release Notes — KIROSHI v0.1.0

> Milestone: Core Platform | Release Date: 2026-09-04

---

## 1. Summary
Milestone v0.1.0 delivers the complete foundational architecture and initial vertical slice for KIROSHI:
- FastAPI modular monolith backend with layered architecture (`api/`, `core/`, `domain/`, `services/`, `repositories/`).
- Relational storage via SQLAlchemy 2.0 and Alembic migrations (`User`, `TouristProfile`, `Trip`, `Itinerary`).
- Server-enforced role-based access control (`TOURIST`, `AUTHORITY`, `RESPONDER`, `ADMIN`) with IDOR protection.
- React 19 + TypeScript authority command dashboard.
- Flutter mobile architecture specification for tourist client.
- 16 automated integration and security tests verified via pytest.

---

## 2. New Features Implemented
- **Authentication**: `POST /api/v1/auth/register`, `POST /api/v1/auth/login`, `POST /api/v1/auth/logout`, `GET /api/v1/auth/me`.
- **Profiles**: `GET /api/v1/tourists/me`, `PUT /api/v1/tourists/me`, `GET /api/v1/tourists/{id}`.
- **Trips**: `GET /api/v1/trips`, `POST /api/v1/trips`, `GET /api/v1/trips/{id}`, `PATCH /api/v1/trips/{id}`, `POST /api/v1/trips/{id}/start`, `POST /api/v1/trips/{id}/stop`.
- **Health**: `GET /api/v1/health`.
- **Authority Portal**: Real-time overview metrics, traveler inspection, trip status filtering, trip conclusion trigger.

---

## 3. Testing & Verification
- **Backend Tests**: 16 passing tests covering auth, unique constraints, cross-user authorization barriers, trip state machine transitions, and the complete end-to-end vertical slice.
- **Dashboard**: Verified production build using TypeScript compiler (`tsc && vite build`).

---

## 4. Security Audits Performed
- IDOR resistance verified: Tourists cannot view or modify trips/profiles belonging to other travelers.
- Password hashing with bcrypt.
- Strict `.gitignore` protecting secrets and virtual environments.

---

## 5. Known Limitations
- Real-time WebSockets and live GPS coordinate ingestion are planned for milestone v0.2.0.
- Risk prediction and anomaly detection are planned for milestone v0.3.0.
- Flutter SDK is not installed on the current developer host; mobile build validation is managed via CI.
